# CodeSentinel 中文演示视频脚本

时长：约 56 秒  
形式：中文无旁白字幕版，可后续叠加旁白。

## 分镜

1. 开场：PR Review 不再只靠人等。
2. 痛点：周期慢、上下文不足、AI 误报。
3. 接入：配置 GitHub App、模型 Provider、项目规则。
4. 触发：开发者提交 Pull Request 后自动进入队列。
5. 分析：拦截层、意图层、架构层并发运行。
6. 输出：健康度评分、合并闸口、P0 Blocker、低风险 Checklist。
7. 闭环：误报/有帮助反馈沉淀为团队质量资产。
8. 结尾：个人和小团队可真实接入，企业化继续扩展数据库、权限和队列。

## 核心文案

- “先判断能不能合，再解释为什么。”
- “不是替代负责人，而是把低价值等待前移给系统。”
- “P0/P1 主动拦截，P2 收敛到报告。”
- “从一次 PR Review，沉淀成团队质量资产。”
